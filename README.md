# 🚀 AI Digit Recognizer

A complete Deep Learning project built using the Kaggle Digit Recognizer competition dataset.

This repository contains:
- 📓 ANN & CNN Kaggle notebooks
- 📤 Competition submission files
- 🧠 Trained CNN model
- 🌐 Full-stack AI web application using React + Flask

---

## 📌 Project Overview

The goal of this project is to classify handwritten digits (0–9) using Deep Learning techniques.

The project started as a Kaggle competition solution and was later converted into a real AI web application where users can draw digits and get instant predictions.

---

## 🧠 Models Used

### 📌 Submission 1 — ANN
- Fully connected neural network
- Baseline deep learning model

### 📌 Submission 2 — CNN
- Convolutional Neural Network
- Better feature extraction
- Improved accuracy compared to ANN
